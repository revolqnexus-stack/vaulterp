GOLDVAULT — USB QUICK GUIDE

============================



OPEN THE APP

  Double-click:  Open GoldVault.bat



  Do not open the "app" folder — that holds program files only.





COPY TO ANOTHER USB

  Copy these three items from the USB root:

    - Open GoldVault.bat

    - README.txt

    - app\   (entire folder — includes your encrypted data)





BACKUP

  Copy Open GoldVault.bat, README.txt, and the app\ folder to safe storage.

  Admin users can also create backups inside the app (Admin → Backup).





IMPORTANT

  - Run only from a USB drive (not from the computer's internal disk).

  - Do not delete app\GoldVaultData — that is your live data.

  - Close GoldVault before unplugging the USB.
